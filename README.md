## 🚀 Getting Started

### Prerequisites

- **Node.js** v18 or later
- **npm** v9 or later

### Local Setup

```bash
# Clone the repository
git clone https://github.com/Harshavardhan-eng/Harshavardhan-portfolio.git
cd Harshavardhan-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
```
